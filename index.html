공시 원문과 확인 사항

    원문 ZIP은 저장소 data/reports에 보관됩니다. API 계정 매칭 내역은 data/audit에 있습니다. 최신 반기·분기 보고서도 보관하지만 아래 연간 비교에는 혼합하지 않습니다.

    • 지배주주 ROE는 지배주주 순이익 ÷ 평균 지배주주 자본입니다. 총자본 ROE는 별도 항목입니다.
    • CAPEX = 유형자산 취득 현금 + 무형자산 취득 현금. 둘 중 하나라도 결측이면 FCF도 결측입니다.
    • 차입금·EBITDA·ROIC·당좌비율·DPO·CCC·시장배수는 주석·추가 입력 검증이 필요하여 자동 산출하지 않습니다.
    • 기술이전 계약금·마일스톤·로열티의 반복성, 연구개발비와 수익 인식은 원문 주석을 확인하세요. 자동 경고는 투자 판단이 아닙니다.
